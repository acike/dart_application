# Tree (ต้นไม้) พื้นฐานใน Dart

เนื้อหานี้สรุปโครงสร้างข้อมูลแบบต้นไม้ (tree) โดยใช้ตัวอย่าง Binary Tree และ Binary Search Tree (BST)

คำสำคัญ
- Node (โหนด): จุดข้อมูลหนึ่งจุดในต้นไม้
- Edge (เส้นเชื่อม): เส้นที่เชื่อมระหว่างโหนด
- Root (ราก): โหนดบนสุด
- Leaf (ใบ): โหนดที่ไม่มีลูก
- Height (ความสูง): จำนวนขอบยาวที่สุดจากโหนดนั้นไปหาใบ

ไฟล์ที่เกี่ยวข้อง
- `tree_node.dart` โครงสร้างโหนดสำหรับบิเนอรีทรี
- `binary_tree.dart` ทราเวิลและตัวช่วยคำนวณ เช่น `height`, `size`
- `binary_search_tree.dart` BST พร้อม `insert`, `search`, `delete`, `inorder`

วิธีรันเดโม
- `dart run lib/data_structure/tree/tree_demo.dart`
