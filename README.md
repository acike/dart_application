# Dart Learning Project

## Tree (ต้นไม้)

ดูตัวอย่างและคลาสที่โฟลเดอร์ `lib/data_structure/tree/`:

- `tree_node.dart`: โหนดของต้นไม้แบบทวินาม (binary tree node)
- `binary_tree.dart`: ฟังก์ชันพื้นฐานของ Binary Tree เช่น traversal และการคำนวณ `height`, `size`
- `binary_search_tree.dart`: การแทรก ค้นหา ลบ สำหรับ BST พร้อม `inorder()`

ตัวอย่างการรันเดโม: `dart run lib/data_structure/tree/tree_demo.dart`

โครงสร้างโปรเจคสำหรับการเรียนรู้ Dart:

```
lib/
├── 01_basics/         # พื้นฐาน Dart
├── 02_variables/      # ตัวแปรและประเภทข้อมูล
├── 03_control_flow/   # การควบคุมการทำงาน
├── 04_functions/      # ฟังก์ชัน
├── 05_classes/        # คลาสและ OOP
└── 06_advanced/       # หัวข้อขั้นสูง
```

แต่ละโฟลเดอร์จะเก็บตัวอย่างโค้ดและคำอธิบายสำหรับแต่ละหัวข้อ

## วิธีการใช้งาน

1. ศึกษาแต่ละหัวข้อตามลำดับ
2. ดูตัวอย่างโค้ดในแต่ละโฟลเดอร์
3. ลองรันและแก้ไขโค้ดเพื่อทำความเข้าใจ
